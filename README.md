# レンタルモニ太 Flutter UI プロトタイプ

## 実装済み
- 待機中画面
- 見守り中画面
- 見守り停止確認ダイアログ（キャンセル／停止する）
- 通信エラー画面（状態を再確認）
- 異常検知カード（確認しました／見守り停止）
- ホーム／設定／利用履歴の下部ナビゲーション
- 操作履歴の記録
- 設定タブからの異常検知・通信エラーのデモ
- 状態を初期化する操作

## 起動方法
1. Flutter SDK と Android Studio の Android SDK をセットアップします。
2. このフォルダーでターミナルを開きます。
3. 次を順番に実行します。

```powershell
flutter pub get
flutter run
```

## 注意
これは画面遷移とボタン動作を確認するためのUIプロトタイプです。
実際のRaspberry Piとのソケット通信、バックグラウンドでの監視、Androidの通知表示は未接続です。
実機連携では通信処理・接続状態管理・通知プラグイン（例：flutter_local_notifications）などを追加してください。
また、現在の「状態を再確認」は復旧を仮定して待機中に戻すデモ動作です。実際の接続確認処理ではありません。
